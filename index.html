💻 Computer म्हणजे काय?

सोप्या भाषेत:

Computer म्हणजे असा electronic device जो आपल्याकडून data घेतो, त्यावर calculation/processing करतो आणि result देतो.

🌍 Real-life example:
Calculator मध्ये 20 + 30 टाकले तर calculator input घेतो, calculation करतो आणि 50 हा output देतो. Computer सुद्धा याच basic idea वर काम करतो, पण खूप मोठ्या प्रमाणावर आणि वेगाने.

Computer चे basic काम:

  • Input घेणे
  • Data process करणे
  • Information store करणे
  • Output देणे
📝 Exam Answer:
A computer is an electronic device that accepts data as input, processes it according to instructions, stores it and produces meaningful output.

📊 Data आणि Information

Data म्हणजे काय?

Data म्हणजे raw facts किंवा values ज्यांचा अजून अर्थपूर्ण result तयार झालेला नसतो.

🌍 Example:
50, 60, 70 हे तीन numbers फक्त data आहेत.

Information म्हणजे काय?

Data process केल्यानंतर मिळणारा useful आणि meaningful result म्हणजे Information.

🌍 Example:
50, 60, 70 ची average = 60. ही average आपल्यासाठी information आहे.

🧠 RAM म्हणजे काय?

सोप्या भाषेत:

RAM म्हणजे computer ची temporary working memory. Computer सध्या कोणते काम करत आहे त्यासाठी RAM वापरली जाते.

🌍 Real-life example:
समज तू अभ्यास करत आहेस. तुझ्या समोर study table आहे. सध्या लागणारी पुस्तके तू table वर ठेवतोस. Table वर जेवढे काम चालू आहे ते RAM सारखे समज. काम संपले किंवा power गेली तर table वरचे temporary arrangement टिकत नाही.

Important points:

  • RAM = Random Access Memory
  • RAM temporary memory आहे.
  • RAM volatile memory आहे.
  • Computer बंद केल्यावर RAM मधील data साधारणपणे टिकत नाही.
📝 Exam Answer:
RAM stands for Random Access Memory. It is a volatile primary memory used to temporarily store data and instructions currently being used by the computer.

💾 Storage म्हणजे काय?

Storage म्हणजे data permanently किंवा long-term save करण्यासाठी वापरली जाणारी जागा.

🌍 Real-life example:
तुझ्या mobile मध्ये photos, videos आणि documents save असतात. Phone बंद केला तरी ते delete होत नाहीत. ही storage ची idea आहे.

Examples:

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card

⚡ RAM vs Storage

Simple trick:
RAM = सध्या चालू काम
Storage = कायम save केलेली माहिती

उदाहरणार्थ तू game खेळत आहेस. Game चालण्यासाठी RAM वापरली जाते, पण game install केलेली files storage मध्ये असतात.

🔢 Number System म्हणजे काय?

सोप्या भाषेत:

Numbers represent करण्याची पद्धत म्हणजे Number System. वेगवेगळ्या number systems मध्ये वेगवेगळे digits वापरले जातात.

🌍 Real-life example:
आपण रोज 0 ते 9 digits वापरतो. त्यामुळे आपली सामान्य counting Decimal Number System मध्ये असते.

मुख्य Number Systems:

  • Decimal – Base 10
  • Binary – Base 2
  • Octal – Base 8
  • Hexadecimal – Base 16

0️⃣1️⃣ Binary Number System

Binary Number System मध्ये फक्त दोन digits असतात: 0 आणि 1.

🌍 Real-life example:
घरातील switch विचार कर: OFF = 0
ON = 1

Computer electronics मध्येही दोन states represent करण्यासाठी binary idea वापरली जाते.
📝 Exam Answer:
Binary is a base-2 number system that uses only two digits, 0 and 1.

⚙️ Operating System म्हणजे काय?

Operating System म्हणजे user आणि computer hardware यांच्यामधला important software layer.

🌍 Real-life example:
तू mobile मध्ये WhatsApp उघडतोस. App ला camera, storage, internet इत्यादी resources लागतात. हे resources manage करण्याचे काम operating system करते.

Examples:

  • Windows
  • Linux
  • Android
  • macOS
📝 Exam Answer:
An Operating System is system software that manages computer hardware and software resources and provides services to users and applications.

🔧 Functions of Operating System

Operating System अनेक important कामे करते.

  • Process Management
  • Memory Management
  • File Management
  • Device Management
  • Security
  • User Interface
🌍 Example:
तू एकाच वेळी music ऐकत आहेस आणि browser वापरत आहेस. OS अनेक running processes manage करते.

🔄 Process म्हणजे काय?

एखादा program execution मध्ये आला की त्याला process म्हणतात.

🌍 Real-life example:
Chrome हा एक program आहे. तू Chrome उघडून त्यात काम सुरू केले की operating system त्याच्यासाठी process manage करते.

🧠 Memory Management

Operating System कोणत्या program ला किती memory द्यायची आणि ती memory कधी release करायची हे manage करते.

🌍 Example:
तू एकाच वेळी browser, music आणि calculator वापरतोस. प्रत्येक application ला memory resources लागतात. OS हे resources manage करते.

👨‍💻 C Programming म्हणजे काय?

C ही general-purpose programming language आहे. तिच्या मदतीने आपण computer ला instructions देऊन programs तयार करू शकतो.

🌍 Real-life example:
आपण एखाद्या व्यक्तीला "पहिले हे कर, मग हे कर" अशा instructions देतो. Programming मध्ये computer ला अशाच instructions दिल्या जातात.
📝 Exam Answer:
C is a general-purpose programming language used to develop system software and application programs.

📦 Variable म्हणजे काय?

Program मध्ये एखादी value temporarily store करण्यासाठी variable वापरला जातो.

🌍 Real-life example:
एका box वर "Age" असा label लावला आणि त्यात 18 ठेवले. Programming मध्ये variable हे त्या labeled box सारखे आहे.

उदाहरण: 

int age = 18;

🔀 if-else Statement

Condition true असेल तर एक काम आणि false असेल तर दुसरे काम करण्यासाठी if-else वापरतो.

🌍 Real-life example:
जर पाऊस असेल → umbrella घे.
नाहीतर → umbrella घेऊ नको. 
if(age >= 18)
{
    printf("Adult");
}
else
{
    printf("Not Adult");
}

🔁 Loop म्हणजे काय?

एखादे काम पुन्हा पुन्हा करायचे असेल तर loop वापरला जातो.

🌍 Real-life example:
"1 ते 100 पर्यंत numbers print कर" प्रत्येक number साठी वेगळा code लिहिण्याऐवजी loop वापरता येतो. 
for(int i=1; i<=5; i++)
{
    printf("%d ", i);
}

🧩 Function म्हणजे काय?

एखादे specific काम करण्यासाठी तयार केलेला reusable block of code म्हणजे function.

🌍 Real-life example:
Calculator मध्ये "Add" हे एक specific काम आहे. त्यासाठी वेगळा function बनवता येतो.

🔢 Matrix म्हणजे काय?

Numbers किंवा values rows आणि columns मध्ये व्यवस्थित मांडल्या असतील तर त्याला Matrix म्हणतात.

🌍 Real-life example:
Classroom मध्ये students ची attendance table: rows = students आणि columns = subjects. ही table matrix सारखी visualize करता येते.
