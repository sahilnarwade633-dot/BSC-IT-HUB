💻 What is Computer?

👉 सोप्या भाषेत:

Computer म्हणजे असा electronic machine जो आपल्याकडून data घेतो, त्यावर processing करतो आणि आपल्याला useful result देतो.

🌍 Real Life Example:
तू calculator मध्ये 20 + 30 टाकतोस. Computer input घेतो → calculation करतो → 50 output देतो.

📝 Exam Answer:

Computer is an electronic device that accepts data as input, processes it according to instructions and produces meaningful output.

🧠 What is RAM?

👉 सोप्या भाषेत:

RAM म्हणजे computer ची temporary working memory. Computer सध्या जे काम करत आहे ते RAM मध्ये temporary store होते.

🌍 Real Life Example:
तुझ्या study table वर तू सध्या जे books ठेवले आहेत ते RAM सारखे आहेत. तू काम संपवल्यावर ते table वरून काढून ठेवतोस.

💡 Important:

Computer बंद झाला की RAM मधील temporary data निघून जातो. म्हणून RAM ला Volatile Memory म्हणतात.

RAM stands for Random Access Memory. It is a temporary and volatile memory used to store currently running data and programs.

💾 What is Storage?

👉 सोप्या भाषेत:

Storage म्हणजे photos, videos, documents, apps आणि इतर data long-term store करण्याची जागा.

🌍 Real Life Example:
तुझ्या mobile मधील Gallery मध्ये videos save राहतात, mobile restart केला तरी ते delete होत नाहीत. हे storage मुळे शक्य होतं.
Storage is used to permanently store data, files and programs. Examples include HDD, SSD and memory cards.

🔢 What is Number System?

👉 सोप्या भाषेत:

Numbers represent करण्यासाठी वापरली जाणारी पद्धत म्हणजे Number System.

🌍 Real Life Example:
आपण रोज 0 ते 9 digits वापरतो. उदा. 25, 100, 500. ही Decimal Number System आहे.

Computer मध्ये?

Computer electronic असल्यामुळे तो मुख्यतः 0 आणि 1 वापरतो. याला Binary Number System म्हणतात.

A number system is a method used to represent numbers using a set of digits. Common systems are Decimal, Binary, Octal and Hexadecimal.

⚡ What is Binary?

👉 सोप्या भाषेत:

Binary मध्ये फक्त दोन digits असतात: 0 आणि 1.

🌍 Real Life Example:
घरातील switch: OFF = 0
ON = 1

Computer मध्येही अशाच प्रकारे 0 आणि 1 चा वापर होतो.
Binary number system uses only two digits, 0 and 1. It is widely used in computers and digital systems.

⚙️ What is Operating System?

👉 सोप्या भाषेत:

Operating System म्हणजे user आणि computer hardware यांच्यामधला manager.

🌍 Real Life Example:
Hotel मध्ये manager customers आणि workers यांचं काम manage करतो. तसंच OS computer मधील resources manage करतो.
An Operating System is system software that manages computer hardware, software resources and provides services to application programs.

🔄 OS Functions

👉 सोप्या भाषेत:

Operating System ची अनेक कामे असतात:

  • Memory Management
  • Process Management
  • File Management
  • Device Management
  • Security
🌍 Real Life Example:
तू music चालू ठेवून WhatsApp वापरतोस. OS दोन्ही applications चे काम manage करते.

👨‍💻 What is C Programming?

👉 सोप्या भाषेत:

C ही एक programming language आहे. याच्या मदतीने आपण computer ला instructions देऊ शकतो.

🌍 Real Life Example:
तू calculator app बनवायची असेल तर calculations करण्यासाठी programming language वापरावी लागते.
C is a general-purpose programming language developed by Dennis Ritchie.

📦 What is Variable?

👉 सोप्या भाषेत:

Variable म्हणजे data ठेवण्यासाठी वापरलेली named memory location.

🌍 Real Life Example:
एका box वर "Marks" असा label लावला. त्या box मध्ये 85 ठेवले. इथे box = variable आणि 85 = value.
A variable is a named memory location used to store a value.

🔀 What is if-else?

👉 सोप्या भाषेत:

Condition check करून decision घेण्यासाठी if-else वापरतात.

🌍 Real Life Example:
जर temperature जास्त असेल तर fan ON, नाहीतर fan OFF.
The if-else statement is used to execute one block when a condition is true and another block when the condition is false.

🔁 What is Loop?

👉 सोप्या भाषेत:

एकच काम पुन्हा पुन्हा करायचं असेल तर loop वापरतात.

🌍 Real Life Example:
"Good Morning" 100 वेळा print करायचं असेल तर 100 वेगवेगळ्या lines लिहिण्याऐवजी loop वापरू शकतो.
A loop is used to repeatedly execute a block of statements until a specified condition is satisfied.

📊 What is Matrix?

👉 सोप्या भाषेत:

Numbers rows आणि columns मध्ये व्यवस्थित arrange केले तर त्याला Matrix म्हणतात.

🌍 Real Life Example:
Class मध्ये students चे marks table मध्ये लिहिले:

Math | Science | English
80 | 75 | 90

हा table matrix सारखा आहे.
A matrix is a rectangular arrangement of numbers or elements in rows and columns.

🔢 Permutation and Combination

👉 सोप्या भाषेत:

Permutation मध्ये arrangement/order important असतो. Combination मध्ये selection important असते.

🌍 Real Life Example:
A, B, C मधून दोन students निवडणे = Combination.
A आणि B ला first आणि second position देणे = Permutation.

🧮 Mathematical Induction

👉 सोप्या भाषेत:

एखादी mathematical statement सर्व natural numbers साठी true आहे हे prove करण्याची पद्धत म्हणजे Mathematical Induction.

🌍 Real Life Example:
Domino ची पहिली tile पडली आणि प्रत्येक tile पुढची tile पाडते, तर सर्व tiles पडतील.
Mathematical induction is a method of proving that a statement is true for all natural numbers.
