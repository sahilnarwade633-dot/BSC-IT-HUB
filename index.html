💻 Computer Fundamentals

Unit 1 — Computer Basics

1. Computer म्हणजे काय?

सोप्या भाषेत:
Computer म्हणजे असा electronic machine जो आपल्याकडून data घेतो, त्यावर processing करतो आणि आपल्याला useful result देतो.
🏠 Real-life Example:
तू calculator मध्ये 10 + 20 टाकतोस → calculator input घेतो → calculation करतो → 30 answer दाखवतो. Computer सुद्धा याच प्रकारे input → processing → output करतो.
लक्षात ठेवा:
  • Input
  • Processing
  • Output
  • Storage
📝 Exam Answer:
Computer is an electronic device that accepts data as input, processes it according to instructions and produces meaningful output.

2. Data आणि Information

Data म्हणजे raw facts किंवा unprocessed माहिती.
Information म्हणजे process केलेला आणि useful झालेला data.
🏠 Real-life Example:
एका class मधील marks: 45, 67, 82, 55 हे Data आहे.
“Class ची average marks 62.25 आहे” हे Information आहे.
📝 Exam Answer:
Data is a collection of raw facts, while information is processed data that has meaningful value.
Unit 2 — Memory and Storage

3. RAM म्हणजे काय?

सोप्या भाषेत:
RAM म्हणजे computer ची temporary working memory. Computer वर सध्या जे काम चालू आहे त्यासाठी RAM वापरली जाते.
🏠 Real-life Example:
समज तुझं study table म्हणजे RAM आहे. तू सध्या ज्या books घेऊन अभ्यास करतोस त्या table वर असतात. काम झाल्यावर त्या cupboard मध्ये ठेवतोस.

इथे Study Table = RAM
Cupboard = Storage
RAM चे महत्त्व:
  • Programs चालवण्यासाठी working space देते.
  • RAM जास्त असेल तर अनेक programs एकाच वेळी चालवणे सोपे होऊ शकते.
  • RAM ही volatile memory आहे.
📝 Exam Answer:
RAM (Random Access Memory) is a temporary and volatile memory used to store data and instructions currently being used by the CPU.

4. Storage म्हणजे काय?

सोप्या भाषेत:
Storage म्हणजे computer मध्ये files, photos, videos, documents आणि software दीर्घकाळ साठवून ठेवण्याची जागा.
🏠 Real-life Example:
तुझ्या room मधलं cupboard समज. तू books आज वापरत नसशील तरी त्या cupboard मध्ये सुरक्षित ठेवू शकतोस. Computer मधील SSD/HDD सुद्धा files साठवतात.
  • SSD
  • Hard Disk
  • Pen Drive
  • Memory Card
📝 Exam Answer:
Storage is used to permanently store digital data such as files, documents, photos, videos and applications.

5. RAM आणि Storage मधला फरक

RAM = सध्या चालू कामासाठीची temporary जागा.
Storage = files कायमस्वरूपी ठेवण्यासाठीची जागा.
🏠 Example:
Study table वर सध्या वापरत असलेली books = RAM.
Cupboard मध्ये ठेवलेल्या सर्व books = Storage.
📝 Exam Point:
RAM is temporary and volatile, while storage is used for long-term data retention.
Unit 3 — Number System

6. Number System म्हणजे काय?

सोप्या भाषेत:
Number system म्हणजे numbers represent करण्याची पद्धत. Computer Science मध्ये वेगवेगळ्या number systems चा उपयोग होतो.
🏠 Real-life Example:
आपण रोज 0 ते 9 digits वापरतो. म्हणून आपली everyday counting system म्हणजे Decimal. Computer मध्ये मात्र Binary खूप महत्त्वाचा आहे कारण computer च्या electronic states ला 0 आणि 1 ने represent करता येते.
मुख्य Number Systems:
  • Decimal → Base 10
  • Binary → Base 2
  • Octal → Base 8
  • Hexadecimal → Base 16
📝 Exam Answer:
A number system is a method of representing numbers using a specific set of digits and a base.

7. Binary Number System

सोप्या भाषेत:
Binary मध्ये फक्त दोन digits असतात: 0 आणि 1. Computer systems मध्ये binary representation अत्यंत महत्त्वाची आहे.
🏠 Real-life Example:
घरचा switch विचार कर:
OFF = 0
ON = 1

Computer मधील binary concept समजण्यासाठी हा simple example लक्षात ठेवू शकतोस.
📝 Exam Answer:
Binary number system is a base-2 number system that uses only two digits, 0 and 1.

⚙️ Operating System-I

Unit 1 — Introduction to OS

1. Operating System म्हणजे काय?

Operating System म्हणजे user आणि computer hardware यांच्यामधील मुख्य interface.
🏠 Real-life Example:
Restaurant मध्ये customer थेट kitchen मध्ये जाऊन food बनवत नाही. Waiter order घेऊन kitchen पर्यंत पोहोचवतो. तसंच user आणि hardware मधील काम OS manage करते.
📝 Exam Answer:
An Operating System is system software that manages computer hardware and provides services for application programs.

2. OS ची Functions

OS computer मधील processor, memory, files, devices आणि programs manage करण्यास मदत करते.
  • Process Management
  • Memory Management
  • File Management
  • Device Management
  • Security
Unit 2 — Process Management

3. Process म्हणजे काय?

Program चालू झाल्यावर त्याला process म्हणतात.
Example:
तू Chrome ची file फक्त install करून ठेवली → Program.
Chrome उघडून वापरायला सुरुवात केली → Running Process.

💻 Programming in C

Unit 1 — C Basics

1. C Programming म्हणजे काय?

C ही general-purpose programming language आहे. Computer ला instructions देण्यासाठी C वापरता येते.
🏠 Real-life Example:
तू एखाद्याला “पहिले 2 pens घे, मग notebook उघड” असं step-by-step सांगतोस. Programming मध्ये computer ला अशाच प्रकारे instructions दिल्या जातात.
📝 Exam Answer:
C is a general-purpose programming language used for developing system software and application programs.

2. Variable म्हणजे काय?

Variable म्हणजे program मध्ये value store करण्यासाठी दिलेले नाव.
Example:
तुझ्या bag वर “Books” असा label लावला आहे. त्या नावाखाली books ठेवतोस.

Programming मध्ये variable सुद्धा data ठेवण्यासाठी एक नाव असते.

3. if-else म्हणजे काय?

if-else वापरून program ला condition नुसार decision घेता येतो.
🏠 Real-life Example:
जर पाऊस पडत असेल → umbrella घे.
नाहीतर → umbrella घेऊ नको.

Computer मध्येही condition true/false तपासून decision घेतला जातो.
📝 Exam Point:
if-else is a decision-making statement used to execute different blocks of statements based on a condition.

4. Loop म्हणजे काय?

एखादे काम पुन्हा पुन्हा करायचे असेल तर loop वापरता येतो.
🏠 Example:
Teacher म्हणतो: “ही line 10 वेळा लिहा.” प्रत्येक वेळेला manually सांगण्याऐवजी programming मध्ये loop वापरता येतो.

📐 Mathematical Foundation M-1

Unit 1 — Matrices

1. Matrix म्हणजे काय?

Numbers किंवा values rows आणि columns मध्ये rectangular form मध्ये arrange केले असतील तर त्याला Matrix म्हणतात.
🏠 Real-life Example:
Class मध्ये students चे marks table मध्ये लिहिले: Rows = students
Columns = subjects
हा table matrix सारखा समजता येतो.
📝 Exam Answer:
A matrix is a rectangular arrangement of numbers or elements in rows and columns.

2. Permutation आणि Combination

Permutation मध्ये arrangement/order महत्त्वाचा असतो. Combination मध्ये selection महत्त्वाचे असते.
🏠 Example:
3 students मधून 2 students निवडायचे → Combination.
त्या 2 students ना first आणि second position द्यायची → Permutation.

3. Mathematical Induction

Mathematical Induction ही mathematical statement अनेक positive integers साठी true आहे हे prove करण्याची पद्धत आहे.
🏠 Example:
Dominoes ची line कल्पना कर. पहिला domino पडला आणि प्रत्येक domino पुढचा domino पाडतो, तर पूर्ण line पडते. Induction मध्येही अशीच basic idea वापरली जाते.
